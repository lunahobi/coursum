# Заметки по архитектуре

## Контекст системы

Проект организован как монорепозиторий, в который входят:
- серверная часть на FastAPI как источник бизнес-логики и данных
- веб-панель на React для администраторов и преподавателей
- мобильный клиент на Flutter для слушателей

Все клиенты работают с серверной частью через REST API и используют единые правила ролевого доступа (RBAC) и контекст организации.

## Подсистемы серверной части

- `auth`: JWT-авторизация, refresh-токены, хеширование паролей
- `tenants`: определение текущей организации, получение данных текущей организации, проверки участия пользователей
- `users`: управление пользователями организации и ролями через записи участия
- `courses` и `lessons`: управление материалами и прогрессом
- `tests`: жизненный цикл адаптивной попытки
- `adaptive`: выбор следующего вопроса и изменение сложности
- `recommendations`: формирование рекомендаций по слабым темам
- `analytics`: панель показателей, прогресс курсов, детальная аналитика слушателя
- `audit`: журналирование событий безопасности и бизнес-действий
- `notifications`: интеграция с внешними уведомлениями (условный/расширяемый слой)

## Изоляция организаций

Изоляция организаций реализована в трех слоях:

1. Слой запроса: организация определяется по поддомену или через `X-Tenant-Code` в демонстрационном режиме и режиме разработки.
2. Слой авторизации: пользователь должен иметь активное участие в текущей организации.
3. Слой данных: все запросы, связанные с организацией, фильтруются по `tenant_id`.

Такой подход достаточно прозрачен для защиты ВКР и при этом демонстрирует практическую изоляцию данных в облачной системе.

## Алгоритм адаптивного тестирования

- Каждый вопрос имеет дискретную сложность от `1` до `5`.
- Попытка начинается с базовой сложности теста.
- Верный ответ повышает целевую сложность на 1.
- Неверный ответ понижает целевую сложность на 1.
- Следующий вопрос выбирается из неиспользованных, ближайших к текущей целевой сложности.
- Слабые темы накапливают штрафы за ошибки и медленные ответы.
- Итог попытки сохраняет балл, слабые темы и сформированные рекомендации.

# История изменений

Все значимые изменения проекта фиксируются в этом файле.

## [Unreleased]

### Добавлено
- Монолитный frontend разделен на модульные страницы и компоненты с выделенной структурой стилей.
- Добавлен стабильный E2E smoke-набор на Playwright и пайплайн отчетов Allure для UI.
- Внедрены инструменты качества кода для backend (`ruff`, `mypy`) и web (`eslint`, `prettier`).
- Добавлен GitHub Actions CI для проверок backend и web.
- Добавлены endpoint проверки БД (`/health/db`) и ограничения частоты auth-запросов.

### Изменено
- Искусственные тренды на дашборде заменены на реальные ряды аналитики из backend.
- Runtime-изменения схемы перенесены в Alembic-миграции и startup-поток миграций.
- Startup-логика переведена на FastAPI lifespan.
- Backend-роуты декомпозированы по доменам (`groups`, `lessons`) из крупных модулей.
- Ужесточены CORS и настройки безопасности для production-окружения.

### Исправлено
- Устранена проблема bootstrap миграций на уже существующей схеме БД.
- Удален frontend-shim для исправления mojibake, поток данных нормализован на источнике.
- Стабилизированы flaky-тесты frontend/backend после модульного рефакторинга и обновления аналитики.
